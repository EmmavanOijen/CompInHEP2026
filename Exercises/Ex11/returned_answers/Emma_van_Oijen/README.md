Note that I assume that the data file is in the same folder. I did not add this in Github due to the filesize.

For Coffea:
I pip installed coffea (no version specified so should be the latest version) in a virtual environment following the lecture 11 example.
Once the environment is activated, one can run "python3 analysis_coffea.py".

For RDatadrame:
There's no need to be in the virtual environment. You can just run "python3 analysis_rdataframe.py".
